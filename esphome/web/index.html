Use Chrome or Edge on a desktop computer. Open this page over HTTPS.
  1. Connect the screen to your computer with a USB-C cable.
  2. Click Install and pick the serial port of the screen.
  3. Set up Wi-Fi when asked, or join the "HA Controller" access point.
  4. Add the screen in Home Assistant (ESPHome integration).
  5. Install the HA Controller integration {{VERSION}} from HACS.

If the board is not detected, hold BOOT while plugging it in.
